Why this page is different

This frontend is intentionally backend-hosted so it works in this environment without Node, npm, or a Vite build. The product behavior still matches the VESTA flow: sign in with Supabase, pick a look, and generate a try-on through the backend.

VESTA demo shell served by FastAPI. If you later install Node/npm, I can switch this back to the full React/Vite build.
